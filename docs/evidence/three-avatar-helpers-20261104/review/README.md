# Review provenance

These documents retain the helpers' implementation/review snapshots. Their
local original commit SHAs differ from the coordinator's published integration
SHAs. Statements that execution was pending refer to the time each snapshot
was written. The completed coordinator runs and exact source identity are in
`../combined/summary.json` and the shared handoff.

The dispatch and audio reviews are original reviewer-written reports. The math
review is explicitly a coordinator record of the independent review message.
