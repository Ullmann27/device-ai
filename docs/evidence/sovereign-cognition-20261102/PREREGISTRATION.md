# Frozen protocol

Hypothesis: preserving whole evidence in the existing context compiler prevents unsupported location answers caused by cutting off late negation. Tradeoff: whole-group omission can lose answerable evidence under tight budgets. No neural weights or parameters will be selected from this corpus.

The 72 generated cases (three fixed random seeds, eight bindings each, three input families) and SHA were written before any product code changes. This is a prospective synthetic evaluation by the implementation author, not an independently authored blind corpus. Compare unchanged parent compiler, candidate compiler, full-text oracle, and empty context through the SAME existing evidence verifier. Keep every wrong answer and abstention. Count answerable abstention separately from correct negative abstention. Stop after one candidate; any further change prompted by these labels requires a new holdout. This evaluates information retention and bounded verified reasoning, not CDX1/Gemma free generation or general intelligence.

CDX1 0/20 and 0/5 correct abstention remain a separate device failure. The experiment tests the **context loss** mechanism only; conditioning collisions, teacher forcing, token/EOS behavior and decoder capacity require additional independent generator experiments.
