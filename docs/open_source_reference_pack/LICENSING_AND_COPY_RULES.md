# Licensing and Copy Rules

Selected upstream projects use permissive licenses at the pinned revisions in SOURCE_INDEX.md.

Rules:
1. Prefer pattern-level adaptation and small ports.
2. Before copying source code, inspect the exact source file for extra headers/notices.
3. Preserve required copyright/license notices.
4. Record upstream repo, file path and pinned SHA for non-trivial copied code.
5. Keep exact upstream license texts under `licenses/`.
6. Model weights have separate licenses; verify every model before bundling/distribution.
7. Do not copy trademarks, branding, screenshots or product identity.
8. Avoid verbatim upstream documentation when a concise engineering summary is enough.
9. Direct reuse must remain reviewable and replaceable behind Device AI interfaces.

This is an engineering compliance checklist, not legal advice.
