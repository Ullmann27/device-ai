## New smallest experiment

Three newly frozen reviewer-owned synthetic tasks, g01→g02→g03, on distinct pure
function boundaries. Exactly one unchanged source file is editable in each task.
Requirements and assertions freeze before any prospective model invocation.
No solution patch is supplied, no external model writes the candidate, and no
fixture is altered after an outcome is known. Deliberately RED test fixtures use
non-test suffixes in this review branch; the materializer alone gives them the
canonical test path in disposable repositories.

A0 is the existing single actual local provider, no inherited memory context and
no extra agent conversation. Each task has at most two reserved model calls and
8192 context characters, one allowed source file, the existing Node test chain,
original native token/deadline caps, and fresh synthetic state. At most three tasks
and six reserved calls total. Calls are serial and wait for Chief's exclusive CPU
gate after Gradle/native compilation. Interrupted or consumed states are inspected,
never automatically rerun in a new directory to erase a failed attempt.

## Genuine admission and scoring

The runtime engineer must first finish the exact approved binary. Reviewer checks
model/binary size, SHA256, public manifest and pinned configuration independently.
Only the original default provider may be used: no providerFactory/fake run,
scripted patch, synthetic brand, patched verifier, cloud fallback or weaker tests.

Use canonical prepareCodingTask → runCodingTask with exact task fingerprint,
requireIsolation=true, requireLocalModelObservation=true, the existing owner-configured
fixed-profile executor and canonical journal. A worktree is not an OS sandbox.
Model/runtime/context/source/task/job/attempt/receipt identities must correlate.

Success requires actual assertion RED, original private-branded genuine inference,
its exact proposal/patch, unchanged real tests GREEN, fresh independent verification
and canonical journal outcome. Test-only success or model prose is insufficient.
Persistence and fresh-process recall are separately scored. An abstention, malformed
response, source mismatch, timeout, isolation failure or failed verification remains
in the denominator with raw evidence. No new inference follows an unknown effect.

Report reserved/admitted calls, accepted/rejected proposals, terminal task status,
source/test hashes, tool receipts, independent verdict, elapsed time and measured
resources with their actual scope. No parent RSS is mislabelled model RSS. Native
resource sampling, if used, must match executable inode and bound the measurement.
