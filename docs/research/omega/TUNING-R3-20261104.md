## Frozen candidates

1. **R3-M1: row-sized NLL scratch.** Existing `nll` allocates `tokens * vocabulary` floats although probabilities are consumed one row at a time. Extend the internal softmax helper with an output-offset overload while retaining its existing signature and expression order; reuse one row in `nll`.
2. **R3-M2: direct next distribution.** Existing `nextDistribution` allocates a sequence-sized output and then copies its final row. Use the same output-offset helper to write directly into its returned row. Do not change logits computation or model architecture.
3. **R3-M3: primitive token assembly.** Existing `encode` boxes token IDs through `ArrayList<Int>` and per-word list views. Preserve pretokenization, merge order, vocabulary and cache semantics while copying cached arrays into one exactly sized primitive result.
