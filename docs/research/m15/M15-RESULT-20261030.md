**Gleiche Qualität nach der Optimierung:** Die markierten Fälle sind pro Kategorie identisch auf DEV (50/50, 0 Fehlalarme) und HOLDOUT2 (48/50, 0 Fehlalarme). Unit-Tests 11/11.

**Wiederverwendung geprüfter Belege (M9-Labor):** Der inhaltsadressierte Testergebnis-Cache führt jeden identischen Lauf (Quelle + Test + Auswahl) nur einmal aus. Alle Arme, die denselben Lauf brauchen, bekommen das Ergebnis samt gemessener Zeit angerechnet. Die Einsparung steht im M9-Bericht.

**Nicht gemessen:** ART auf dem Fold7, Akku, Speicher auf dem Gerät. F2 (GPU, Expertenstreaming, Großmodelle) wurde **nicht** praktisch untersucht, weil in dieser Umgebung keine passende Hardware vorhanden ist.
