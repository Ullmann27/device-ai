Teacher preservation reduces the observed short-continuation collapse versus
replay, but loses both original 32-token successes and restricted retention.

The data are authored, shortcut-prone and openly inspected DEV, not a blind test.

## Reproduction

The two analyzers accept explicit paths (`--help`); immutable registrations bind
the actual execution environment. Pure diagnostic tests use repository fixtures:

```sh
python3 experimental/weight-space-20261110/evaluation/contrast-audit-v1/test_analyze_contrast.py --fixture-root experimental/weight-space-20261110 -v
python3 -m unittest discover -s experimental/weight-space-20261110/data/contrast-pair-audit-v1 -p 'test_*.py' -v
python3 experimental/weight-space-20261110/evaluation/distill-v1/test_analyze_distill.py --fixture-root experimental/weight-space-20261110 --base-analyzer experimental/weight-space-20261110/evaluation/contrast-audit-v1/analyze_contrast.py --java-reference 36,24,8,0,32,55,19,45,57,18,12,16 -v
```

Native compilation reuses `training/build_experiment.py`, pinned #530 sources
and the three `training/distill-v1/*.kt` files. Inspect and loss checks make no
candidate update. Never overwrite a registration or run directory to rerun;
bind a different environment explicitly. Original raw receipts remain immutable.
