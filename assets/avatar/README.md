# JARVIS local 3D research candidate

`jarvis-research-v1.glb` is the canonical portable asset. `jarvis-research-v1.blend` preserves the same authored Blender scene for visual inspection. Both are generated by `tools/avatar-3d/build_bust.py` and `export_glb.py`; no image is projected onto the mesh.

Original license statements, immutable URLs, byte counts, and SHA256 records: `tools/avatar-3d/vendor/makehuman/`. No MakeHuman source code imported. This candidate is an independently adapted licensed mesh. It does not establish exact facial identity or owner visual acceptance.

Contract, actual asset hash, pivots, target order, topology and symmetry metrics, validator reports and same-mesh renders: `docs/avatar-live/geometry-work/`. Runtime uses one existing AvatarPose interface. No TTS pipeline, camera, or Android source is introduced here.

The entire Face skin includes head, neck, and shoulders. Neutral is all morph weights zero. Anatomical left is +X; glTF +Y is up and +Z is front; units metres. `JawOpen` morph animates exterior skin; the separate `Jaw` node controls the lower dental arch/interior. No facial-normal corrective targets or production phonetic tuning are claimed.

Rebuild (Blender4.3.2, CPU2, no network):

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 blender -b -t 2 --python tools/avatar-3d/build_bust.py
node tools/avatar-3d/validate-glb.mjs assets/avatar/jarvis-research-v1.glb docs/avatar-live/geometry-work
```

`-- --preview` renders four diagnostic views instead of30. Khronos validator dependency is pinned in `tools/avatar-3d/package-lock.json`; install with `npm ci --ignore-scripts` in that directory if needed.
